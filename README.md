# Operation-Bravo Source Code Base
A fully-integrated and unified Roblox Tactical FPS and Anti-Cheat compilation framework. 

## Included Modules
- **Game Engine**: Custom lean-mechanics, procedural weapon model generation (M4A1, DLQ33, Saqire367 Dragon), physical flight controllers, carry overrides, and droids.
- **Atmospheric Corrections**: Procedural Bloom/ColorCorrection and loading sequences.
- **Telemetry Anti-Cheat (Devios Sentinel)**: Authoritative movement vector validation, cryptographic heartbeat sequences, and rate limiters.
- **Rollback Engine (NovaAC)**: 3D oriented bounding box (OBB) slab testing and history buffers.
- **Translated Environment Metrics (pulsar-pwnzor)**: Roblox ported checks for aspect-ratio distortions, FOV modifications, and AFK timeouts.
